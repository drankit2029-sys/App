## Data Safety (Google Play Console)

Fill the form using these answers (truthful as of v1.3.0):

| Question | Answer |
|---|---|
| Does your app collect or share any of the required user data types? | **Yes** |
| Is all of the user data encrypted in transit? | **Yes** (AdMob requests use HTTPS) |
| Data types collected/shared | **Device or other IDs** (advertising ID — used by Google AdMob, only with consent; shared) |
| Does any collected data get shared with third parties? | **Yes** (ad identifier to Google) |
| Can users request deletion? | **Yes** — uninstall deletes everything |
| Is the data collection optional? | **Yes** — EEA/UK/CH users choose via consent form; other regions via system ad settings |
| Is data used for personalization, ads? | **Yes** (non-personalized ads served to consent-refusing users) |
| Any audio/recordings recorded in the app collected? | **No** |
| Account required? | **No** |

Pro users who don’t consent: ads never load (ad container is hidden when
entitled), so no ad-related data leaves the device in that mode.

## Content rating (IARC questionnaire)

- Violence / sexual content / language / controlled substances / gambling: **No**
- User interaction (chat, sharing of audio via external apps): **Yes** — user can
  share exported files via the Android share sheet (files only, no chat).
- Unsupervised sharing of user creations to others: **Yes**
- Digital purchases / real money: **Yes**
- Ads: **Yes**
- Content generated by AI: **No**

Expected outcome: **Everyone** (ESRB Everyone, PEGI 3, USK 0).

`RECORD_AUDIO`, `FOREGROUND_SERVICE_MICROPHONE`, `FOREGROUND_SERVICE_DATA_SYNC`,

essentials are capped at `maxSdkVersion=28`.

## Steps still needed (Console, after this branch merges)

1. Create/access the AdMob app entry; add 4 ad units (Native advanced, anchored
   adaptive banner, interstitial, App open) — see AdMobManager usage.
2. Upload icon (click **Graphics**), feature graphic, screenshots.
3. Paste text from `fastlane/metadata/android/en-US/`.
4. Set Data Safety, IARC questionnaire exactly as above.
5. Declare privacy policy URL in App content → Privacy policy.
6. Upload the release AAB (`app-release.aab`), signed with your real keystore
   (replace the CI-test-key APKs — they cannot be published).
7. Run the internal-testing track first; verify install + entitlement restore.
8. If targeting EEA/UK/CH: publish the UMP consent message in AdMob first.
